---
I played around with installing Gemma 4 locally. It's a large language model that can run on consumer hardware, and while it taxes my MacBook Air's 16GB of RAM, it's pretty impressive. I was able to converse with it and link it with my VS Code IDE. I need to get some more coding done to fully evaluate it, but my initial impression is good. It's not as powerful as the latest cloud-based models, but it's a great option for offline use and has a lot of potential for customization.

One thing I appreciate about running it locally is getting a better understanding of context windows, token usage, grounding and the tradeoffs between model size and performance. It's one thing to use a cloud-based API and not worry about those details, but running it locally forces you to think about these things more deeply.
