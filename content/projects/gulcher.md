My first playful experiment in vibe coding using Codex, this also helps solve a real problem for a friend who recently moved into a new apartment complex next to the Mercedes Benz Stadium. This scrapes events from the local venues to generate an ICS file and web calendar of combined local events. The goal is to provide an at-a-glance expectation of local traffic.
